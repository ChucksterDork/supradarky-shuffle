Import a YouTube playlist

Paste a public or unlisted playlist URL to import its individual videos, titles, and order. YouTube requires a Data API key for this feature. The key stays in this browser, not in the website source. Enable YouTube Data API v3 and create an API key. Restrict the key to this website's GitHub Pages domain and the YouTube Data API v3.

The playlist title becomes the collection name. Individual YouTube video titles are searchable; game/composer fields are not automatically available. Private playlists require a different authorization method. Large playlists may take a moment to import.

Add a collection

Accepts the SupraDarky CSV, CSV exports with a URL/link column, or a text file with one YouTube video URL per line. For direct playlist URLs, use the importer above.

For soundtrack browsing, import a CSV with columns such as URL, Title, Game, Composer. Plain video links will play, but will display generic titles until metadata is provided.
