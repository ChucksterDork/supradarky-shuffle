YouTube API access

Required for YouTube playlist and timestamped-video imports. Use your restricted YouTube Data API v3 key.

Import a playlist

Imports individual YouTube videos with their titles. Public and unlisted playlists are supported.

Individual video titles are searchable. Private playlists require different authorization. Large playlists may take a moment to inspect.

Import a timestamped video

Detect and review individual songs, then create a new collection/soundtrack or add them to an existing one.

Review or edit the list below. One track per line: MM:SS Song title or HH:MM:SS Song title. Each track ends when the next begins; the last ends at the video's duration. Delete unwanted lines.

Import a file or links

Import a CSV with YouTube video URLs and optional song metadata, or a TXT file containing one YouTube video URL per line. For YouTube playlists, choose the playlist import option.

For soundtrack browsing, import a CSV with columns such as URL, Title, Game, Composer. Plain video links will play, but will display generic titles until metadata is provided.

Manage saved libraries

Enable, rename, reclassify or remove your music libraries. Changes are saved in this browser.

Manage source videos

Remove a single soundtrack video and all its timestamped songs without deleting the collection.
